name=Landslide Ground-Truthing
qgisMinimumVersion=3.44

description=Ground-truth a seismically detected landslide: pre/post Sentinel-2, Landsat, PlanetScope, Maxar and SAR imagery, optical+SAR change fusion, a 3D terrain viewer and scar-to-volume estimates.
about=Enter a landslide detection (origin time and epicentre) once, then search and compare pre- and post-event imagery from Sentinel-2, Landsat, PlanetScope, Maxar VHR (GEGD Pro) and Sentinel-1/NISAR radar; fuse optical and radar change into one landslide score; read the scar against the terrain in 3D (ArcticDEM or your own DEM); and turn the outline you digitize into a volume (Larsen et al. 2010 area-volume scaling). "Try an example" in the Detection box loads a real event to start from.

    SETUP: the imagery searches run in a separate Python that the plugin installs itself the first time - click "Install imagery tools" at the top of the panel (about 300 MB to download, 1 GB on disk; nothing is installed into QGIS). It downloads uv (Astral, MIT/Apache-2.0) from PyPI, a standalone Python 3.12 and a pinned, hash-checked package set including PyTorch (for the snow-robust cloud mask) into your user data folder; "Remove" deletes all of it. Volume, Fusion and Maxar VHR work without it.

    ACCOUNTS: Sentinel-2, Landsat, Sentinel-1 and ArcticDEM need none. PlanetScope needs a Planet account (paid). Maxar VHR needs a GEGD Pro API key (US government users). NISAR and the RGI glacier outlines need a free NASA Earthdata login.

    COVERAGE: built for Alaska (glacier outlines and DEM fetch); the optical and radar searches work worldwide.

    PLATFORMS: tested on macOS with QGIS 3.44 and 4.2. Windows and Linux are expected to work but are untested - please report problems on the issue tracker.
